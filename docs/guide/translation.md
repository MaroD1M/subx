# 翻译设置

> 适用版本：v2.11.1
>
> 前置条件：已完成 [快速开始](../getting-started.md)。

本页覆盖 AI 连接、翻译行为、性能参数、智能增强、质量校验、风格与术语表。部署与模型侧参数见 [环境变量参考](../reference/environment.md)。

## AI 连接

### NAS 本地模型

如果模型运行在 NAS 或局域网内，推荐使用 OpenAI 兼容地址：

| 服务 | 示例地址 | 说明 |
| --- | --- | --- |
| Ollama | `http://NAS_IP:11434/v1` | 推荐设置 `OLLAMA_HOST=0.0.0.0` |
| LM Studio | `http://NAS_IP:1234/v1` | 需启动 Local Server |
| llama.cpp | `http://NAS_IP:8080/v1` | 以实际监听端口为准 |
| vLLM | `http://NAS_IP:8000/v1` | 适合 GPU/并发场景 |

Docker 内不要写 `localhost`，请使用 NAS 局域网 IP、容器服务名或 `host.docker.internal`。如果模型列表接口不可用，请开启“手动填写模型名称”。

Anthropic 和 Gemini 使用各自原生协议，当前以非流式请求为主；OpenAI 兼容模式支持流式输出。OpenCode Go 通过 OpenAI 兼容的 Go 网关接入，当前阶段只使用 Chat Completions 协议。

| 设置项 | 说明 |
|--------|------|
| 接口密钥 | 大语言模型的 API Key，必填 |
| Provider 类型 | OpenAI 兼容 / OpenCode Go / Anthropic 原生 / Gemini 原生 |
| 接口基础地址 | OpenAI 兼容默认 `https://api.openai.com/v1`；OpenCode Go 默认 `https://opencode.ai/inference/go/openai/v1`；Anthropic 默认 `https://api.anthropic.com/v1`；Gemini 默认 `https://generativelanguage.googleapis.com/v1beta` |
| 默认模型 | 用于翻译的模型名称，支持获取列表或手动输入 |

## 默认翻译行为

| 设置项 | 说明 |
|--------|------|
| 目标语言 | 翻译的目标语言，默认 `zh-CN`（简体中文） |
| 输出模式 | 仅译文 / 双语对照 / 仅导出原字幕 |
| 翻译模式 | 非流式（推荐）/ 流式（兼容性较弱） |

### OpenCode Go

选择 Provider 类型「OpenCode Go」，填入 OpenCode Console 创建的 API Key，基础地址使用默认值 `https://opencode.ai/inference/go/openai/v1` 即可。

- SubX 会自动发送 `x-opencode-session` 和 `SubX/<version>` User-Agent；会话 ID 按任务隔离。
- 当前阶段只使用 OpenAI Chat Completions 协议；如果某个模型返回协议不支持，请先切换模型或使用 OpenAI 兼容供应商。
- 模型列表来自 Go 网关；列表失败时可以手动填写模型 ID，例如 `deepseek-v4.1-flash`。
- 免费模型通常只允许在 OpenCode 客户端内使用，第三方客户端可能返回 403；订阅额度和区域限制以 OpenCode Console 为准。

## 性能参数

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 分块大小 | 5000 | 估算的 token 数上限，范围 100-50000，越大单次 AI 调用处理的条目越多 |
| 并发任务数 | 3 | 同时运行的任务数量上限 |
| 最大重试次数 | 3 | 单块翻译失败后的重试次数 |
| 日志保留天数 | 7 | 任务日志、AI 日志、临时文件和翻译缓存的保留天数 |

> **分块大小建议**：模型上下文越大（如 128K），此值可以设得越高。字幕条目较少（<200 条）时设 8000-10000 可使所有条目合并到一个块中一次翻译完成。

## 智能增强

「设置 → 智能增强」集中管理以下能力：

| 功能 | 说明 |
| --- | --- |
| 简繁双输出 | 简体任务额外生成繁体，繁体任务额外生成简体；只转换译文，不重复调用模型 |
| 字幕技术质检 | 检查单行过长、行数过多、CPS、时长、重叠、间隔和残留英文 SDH 标记；默认关闭 |
| 自动换行修正 | 只处理超长行，不改变译文语义；可能生成最多两行 |
| 翻译记忆 | 核对导出时学习人工修改；可从媒体库已有双语字幕批量学习；高频短语可作为术语候选加入术语表；支持按目标语言清空记忆 |
| 成本预算 | 按输入/输出每百万 token 价格记录费用，设置月度上限 |
| TMDB 元数据 | 可选填写 TMDB v3 API Key；默认不自动搜索，可在文件浏览器手动搜索，或开启“自动搜索并填充” |

成本预算启用后：

- 手动创建任务、目录监控和自动补齐都会检查本月已用费用。
- 自动任务在预算耗尽时暂停，不会继续创建新任务。
- 翻译历史「运行与诊断」展开后显示本月已用、剩余预算、队列预计和翻译记忆数量。
- 价格按统一单价估算，不区分不同模型的实际计费；适合个人用量控制，不作为账单依据。

## 备用供应商回退

- 设置页「AI 连接 → 失败回退」可启用备用供应商。
- TMDB 自动搜索默认关闭；开启后才会在任务创建、目录监控和自动补齐时自动匹配。文件浏览器可手动「搜索 TMDB」或「清空」当前片名与背景。
- 主供应商重试后仍有缺译或失败条目时，SubX 会用备用供应商补译这些条目。
- 适合把主供应商设为云端高质量模型，备用供应商设为本地 Ollama 或低价模型。
- 备用 API Key 与其他密钥一样加密保存；备用供应商只在主供应商失败后使用。

## 双模型质量校验

在「设置 → 翻译默认」开启：

| 设置项 | 说明 |
|--------|------|
| 校验模型 | 必须与主翻译模型不同，例如主模型 `deepseek-chat`，校验模型 `gpt-4o-mini` |
| 低分阈值 | 默认 70%，低于阈值进入核对 |
| 最多校验条数 | 默认 200，避免长任务产生过多额外调用 |

校验流程：

```text
主模型翻译 → 第二模型逐条评分 → 低分条目进入核对 → 导出
```

- 质量校验失败不会让任务失败，只记录警告。
- 核对页显示 `质量 xx%` 和问题标签。
- 任务详情显示校验模型、平均分和问题统计。
- 核对重译会清除该条旧质量评分。
- 核对页支持按低质量/高质量/未校验筛选。

## AI 校对与术语学习

核对页顶部点「AI 校对」：

- **术语提取建议**：专门从当前任务提取人名、地名、组织名、称号和固定译法。
- **一致性检查**：检查译名、术语前后不一致和明显误译，同时返回「统一译法建议」。
- AI 校对只生成建议，不会自动修改「当前译文」或「最终导出」。
- 结果会按任务和校对类型缓存。重新进入页面、误点或切换面板不会重复调用模型。
- 缓存会显示生成时间、模型和抽样条数；字幕内容变化后会提示缓存可能过期，可手动「重新校对」。
- 两种模式都可能返回术语。一致性检查中的术语更适合叫「统一译法建议」；与「术语提取建议」重复的条目会自动省略，避免重复加入。
- 术语条目可点击相关字幕编号定位；可逐条加入或全部加入全局术语表，只影响后续新任务。
- 批量加入前会提示新增、覆盖和已存在数量；若已有不同译法会要求确认覆盖。
- 一致性问题可点击「定位」跳转到对应字幕，也可以「只看问题字幕」「选中问题字幕」或直接「重译问题字幕」。
- 有 AI 问题时会出现在筛选区和字幕标记中，可与未翻译、低质量等筛选组合使用。
- 长片会抽样检查，结果仅供人工确认。

## 内置与自定义翻译风格

内置风格覆盖常见影视类型：通用标准、粗犷犯罪/废土、英伦谍战/黑色幽默、历史正剧、现代喜剧、硬核科幻、日漫奇幻、家庭伦理、医疗职场、犯罪调查、古装武侠、奇幻史诗、青春校园、恐怖灵异、战争军事、纪录片旁白、脱口秀、文艺作者电影、儿童合家欢、法律政治和音乐歌舞。

在设置页“自定义翻译风格”区域可以新增、编辑和删除风格。每个风格包含名称、适用场景说明和 Prompt；新任务创建时会把当时选中的风格 Prompt 快照写入任务，避免后续修改影响历史任务。

推荐的自定义风格写法：

```text
请使用自然、克制的影视口语，避免书面语。
角色名必须与术语表一致。
不要使用网络流行语和过度本地化表达。
遇到双关语时优先保留人物语气，不必逐字直译。
```

## 术语库管理

「术语库」页面独立管理全局和系列术语：

- 每条术语支持原文、译文、源/目标语言、作用域、分类、备注、优先级、启用和锁定。
- 系列术语优先于全局术语；同 scope 下优先级高的条目后应用。
- 支持 CSV / JSON 导入导出；导入前可预览新增、更新、跳过和错误。
- 术语列表默认每页 20 条，可切换 20 / 50 / 100 条，并支持页码跳转。
- 每次修改记录逐条审计；可创建命名快照并整体回滚。
- 核对页 AI 校对加入术语时写入全局术语库；系列术语可在术语库页面维护。

> 旧版设置页的全局术语表会自动迁移到术语库；保存旧接口时也会同步，兼容历史客户端。

## 术语表与高级设置

| 设置项 | 说明 |
|--------|------|
| 流式使用量统计 | 仅在使用流式模式时建议开启，可获取精确 token 用量 |
| 术语表 | 推荐在「术语库」页面维护；旧版设置页的键值对仍兼容并自动同步到术语库 |
