## 快速开始

### 首次访问

1. 打开浏览器访问 `http://<主机IP>:3000`
2. 首次访问会跳转到 `/login`，设置一个访问口令（最少 8 位）
3. 设置成功后自动登录

### 配置 AI 接口

1. 点击桌面左侧导航或移动端底部导航的「设置」，进入 `/settings` 页面
2. 在 AI 连接区域填写：
   - **接口密钥**：你的 API Key
   - **接口基础地址**：如果使用第三方代理/中转，修改此地址
   - **默认模型**：点击刷新按钮获取可用模型列表，或手动输入模型名
3. 测试连接是否正常：模型列表成功加载即为正常

### 配置媒体库

1. 点击桌面左侧导航或移动端底部导航的「媒体库」
2. 左侧列表选择媒体库，右侧编辑名称、容器内路径和状态
3. 添加一个或多个容器内路径（注意是**容器内路径**，不是宿主机路径）
4. 例如 Docker 挂载了 `/volume1/video:/media/movies`，则应填写 `/media/movies`
5. 点击「检测」或「批量检测」确认挂载和权限正常
6. 保存配置。保存后会留在当前页面，可继续编辑或开启自动监控

媒体库页面会校验空名称、空路径、重复路径和默认库，并标记异常状态。媒体库较多时，左侧列表支持按名称/路径搜索，以及按全部、启用、停用、异常、监控中筛选；右侧只编辑当前选中的媒体库，类似 Sonarr / Radarr 的 master-detail 设置页。保存时只重新检测新增或路径变化的媒体库；需要刷新全部状态时使用「批量检测」。自动监控需要先保存媒体库；停用或删除媒体库会自动关闭其自动监控。删除媒体库不会删除宿主机文件。

### 开始第一个翻译任务

1. 返回首页，在文件浏览器中选择一个视频文件（支持 `.mkv`、`.mp4`、`.avi`、`.webm`、`.ts`）
2. 左侧视频窗格会自动探测字幕轨道，选择需要的轨道
3. 右侧翻译选项区域设置参数
4. 点击"开始翻译"

## 设置页面

设置页使用独立页面和左侧 Tab 导航。存在未保存修改时，切换路由或关闭浏览器会提示确认，避免配置丢失。新增「系统体检」分页，可检查数据库、媒体库、FFmpeg、字体、临时目录、磁盘、AI 配置和备份状态：

- **AI 连接**：密钥、接口地址、默认模型。
- **语音识别**：内置 ASR/OCR 地址、识别参数、模型下载、暂停/续传/代理。
- **翻译默认**：目标语言、输出模式、翻译模式、分块大小、并发、重试、日志保留。
- **翻译风格**：自定义风格管理和内置风格参考。
- **术语表**：专有名词、角色名和固定译法。
- **高级设置**：流式用量统计等兼容性选项。

> Docker 部署环境变量、Compose 参数和逐项注释见 [部署文档第 4 节](deployment.md#4-环境变量与参数) 与根目录 [`docker-compose.yml`](../docker-compose.yml)。

### AI 连接

#### NAS 本地模型

如果模型运行在 NAS 或局域网内，推荐使用 OpenAI 兼容地址：

| 服务 | 示例地址 | 说明 |
| --- | --- | --- |
| Ollama | `http://NAS_IP:11434/v1` | 推荐设置 `OLLAMA_HOST=0.0.0.0` |
| LM Studio | `http://NAS_IP:1234/v1` | 需启动 Local Server |
| llama.cpp | `http://NAS_IP:8080/v1` | 以实际监听端口为准 |
| vLLM | `http://NAS_IP:8000/v1` | 适合 GPU/并发场景 |

Docker 内不要写 `localhost`，请使用 NAS 局域网 IP、容器服务名或 `host.docker.internal`。如果模型列表接口不可用，请开启“手动填写模型名称”。

Anthropic 和 Gemini 使用各自原生协议，当前以非流式请求为主；OpenAI 兼容模式支持流式输出。

| 设置项 | 说明 |
|--------|------|
| 接口密钥 | 大语言模型的 API Key，必填 |
| Provider 类型 | OpenAI 兼容 / Anthropic 原生 / Gemini 原生 |
| 接口基础地址 | OpenAI 兼容默认 `https://api.openai.com/v1`；Anthropic 默认 `https://api.anthropic.com/v1`；Gemini 默认 `https://generativelanguage.googleapis.com/v1beta` |
| 默认模型 | 用于翻译的模型名称，支持获取列表或手动输入 |

### 默认翻译行为

| 设置项 | 说明 |
|--------|------|
| 目标语言 | 翻译的目标语言，默认 `zh-CN`（简体中文） |
| 输出模式 | 仅译文 / 双语对照 / 仅导出原字幕 |
| 翻译模式 | 非流式（推荐）/ 流式（兼容性较弱） |

### 性能参数

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 分块大小 | 5000 | 估算的 token 数上限，范围 100-50000，越大单次 AI 调用处理的条目越多 |
| 并发任务数 | 3 | 同时运行的任务数量上限 |
| 最大重试次数 | 3 | 单块翻译失败后的重试次数 |
| 日志保留天数 | 7 | 任务日志、AI 日志、临时文件和翻译缓存的保留天数 |

> **分块大小建议**：模型上下文越大（如 128K），此值可以设得越高。字幕条目较少（<200 条）时设 8000-10000 可使所有条目合并到一个块中一次翻译完成。

### 双模型质量校验

在「设置 → 翻译默认」开启：

| 设置项 | 说明 |
|--------|------|
| 校验模型 | 必须与主翻译模型不同，例如主模型 `deepseek-chat`，校验模型 `gpt-4o-mini` |
| 低分阈值 | 默认 70%，低于阈值进入核对 |
| 最多校验条数 | 默认 200，避免长任务产生过多额外调用 |

校验流程：

```text
主模型翻译 → 第二模型逐条评分 → 低分条目进入核对 → 导出
```

- 质量校验失败不会让任务失败，只记录警告。
- 核对页显示 `质量 xx%` 和问题标签。
- 任务详情显示校验模型、平均分和问题统计。
- 核对重译会清除该条旧质量评分。
- 核对页支持按低质量/高质量/未校验筛选。

### AI 校对与术语学习

核对页顶部点「AI 校对」：

- **术语提取建议**：专门从当前任务提取人名、地名、组织名、称号和固定译法。
- **一致性检查**：检查译名、术语前后不一致和明显误译，同时返回「统一译法建议」。
- AI 校对只生成建议，不会自动修改「当前译文」或「最终导出」。
- 结果会按任务和校对类型缓存。重新进入页面、误点或切换面板不会重复调用模型。
- 缓存会显示生成时间、模型和抽样条数；字幕内容变化后会提示缓存可能过期，可手动「重新校对」。
- 两种模式都可能返回术语。一致性检查中的术语更适合叫「统一译法建议」；与「术语提取建议」重复的条目会自动省略，避免重复加入。
- 术语条目可点击相关字幕编号定位；可逐条加入或全部加入全局术语表，只影响后续新任务。
- 批量加入前会提示新增、覆盖和已存在数量；若已有不同译法会要求确认覆盖。
- 一致性问题可点击「定位」跳转到对应字幕，也可以「只看问题字幕」「选中问题字幕」或直接「重译问题字幕」。
- 有 AI 问题时会出现在筛选区和字幕标记中，可与未翻译、低质量等筛选组合使用。
- 长片会抽样检查，结果仅供人工确认。

### 内置与自定义翻译风格

内置风格覆盖常见影视类型：通用标准、粗犷犯罪/废土、英伦谍战/黑色幽默、历史正剧、现代喜剧、硬核科幻、日漫奇幻、家庭伦理、医疗职场、犯罪调查、古装武侠、奇幻史诗、青春校园、恐怖灵异、战争军事、纪录片旁白、脱口秀、文艺作者电影、儿童合家欢、法律政治和音乐歌舞。

在设置页“自定义翻译风格”区域可以新增、编辑和删除风格。每个风格包含名称、适用场景说明和 Prompt；新任务创建时会把当时选中的风格 Prompt 快照写入任务，避免后续修改影响历史任务。

推荐的自定义风格写法：

```text
请使用自然、克制的影视口语，避免书面语。
角色名必须与术语表一致。
不要使用网络流行语和过度本地化表达。
遇到双关语时优先保留人物语气，不必逐字直译。
```

### 术语表与高级设置

| 设置项 | 说明 |
|--------|------|
| 流式使用量统计 | 仅在使用流式模式时建议开启，可获取精确 token 用量 |
| 术语表 | 在设置页的“术语表”区域维护原文/译文键值对，如 `Jedi -> 绝地` |

## 文件浏览与字幕选择

### 文件浏览器布局

页面采用响应式工作台布局：

- **桌面端**：左侧目录树 + 右侧文件详情和翻译设置，可拖动调整分栏。
- **平板/窄屏**：目录树和设置区域自动收窄，避免横向滚动。
- **移动端**：顶部「文件 / 翻译设置」Tab 切换；底部保留主导航。

文件浏览器支持：

- 目录展开/折叠和展开状态记忆。
- 当前媒体库切换。
- 快速筛选当前已加载目录。
- 多选模式：点击「多选」后可勾选多个文件，或直接勾选目录前的复选框递归选择该目录内的全部视频。
- 目录勾选只加入视频文件；与视频同名的外挂字幕由视频自动匹配，不会单独重复入队。
- 批量模式可设置字幕/音轨语言优先、是否优先默认轨、是否允许强制字幕轨，以及无字幕时是否回退 ASR。

### 选择视频文件

点击 `.mkv`、`.mp4`、`.avi` 等视频文件后，系统会自动探测内嵌字幕轨道，在右侧显示：

- 轨道编号、语言、编码等信息
- 绿色标记表示支持的字幕轨道
- 点击"选择此轨道"确认

### 直接使用外挂字幕

直接点击 `.srt`、`.vtt`、`.ass`、`.ssa` 文件（无需先选视频），系统将以此外挂字幕为源进行翻译。

### 翻译选项

开始翻译前可在右侧面板的三个分页中调整：

| 分页 | 选项 | 说明 |
|------|------|------|
| 字幕与轨道 | 字幕/音频轨道、ASR、OCR | 选择字幕来源 |
| 翻译设置 | 翻译风格、目标语言、片名、剧情背景、额外要求 | 只影响翻译内容和语气 |
| 字幕输出 | 输出模式、字幕格式、双语布局、预设与高级样式 | 只影响最终字幕文件 |

字幕输出分页中的关键选项：

- **输出模式**：仅译文 / 双语 / 仅原文字幕。
- **字幕格式**：SRT / ASS / SRT+ASS。
- **双语布局**：译文在上 / 原文在上。
- **样式预设**：简洁双语、影院双语、学习双语、紧凑双语、单色双语、单语清爽、单语紧凑、沿用原样式。
- **高级样式**：原文和译文可分别设置字体、字号、文字颜色、描边颜色、描边宽度、阴影、加粗、斜体、垂直边距和对齐；双语模式还可设置行距。
- **字体**：使用可搜索字体选择器，可从推荐 CJK 字体、服务器已安装字体中选择，也可直接输入任意字体名。列表会标记字体是否已安装在服务器上。ASS 只记录字体名，不嵌入字体，播放端需要安装对应字体才能完全还原。
- **SRT 限制**：SRT 不保存字体、颜色和描边；需要视觉样式时请选择 ASS 或 SRT + ASS。
- **示例背景预览**：以 1920×1080 比例快速预览原文/译文的大小、颜色、描边、布局和背景框。
- **实景预览**：选择视频后打开「实景预览」开关，SubX 会从视频中抽取一帧，并用服务器端 FFmpeg + libass 把当前字幕样式烧录到完整分辨率画面上。可以拖动时间点切换画面，点击「原图」查看 100% 尺寸，或下载 PNG 预览图。

> 实景预览使用服务器字体。若所选字体未安装，预览会自动回退并在字体输入框下方提示；最终播放效果仍取决于播放端是否安装该字体。Docker 镜像已内置 Noto Sans CJK、文泉驿微米黑和 DejaVu Sans，也可以把自定义字体挂载到容器的 `/fonts` 目录。

高级设置中的上下文信息会写入任务，并注入翻译 Prompt：

- **片名 / 剧集名**：帮助模型识别作品和集数。
- **剧情背景 / 人物关系**：帮助模型理解本集剧情、称呼和人物关系。
- **额外翻译要求**：例如角色名保持一致、不要使用网络流行语、保留特定术语等。

跨块翻译时，每个文本块还会自动携带：

- 当前块之前 6 条作为前文语境
- 当前块之后 6 条原文作为后文预看
- 后文只用于理解代词、语气和剧情衔接，不会被翻译或拼接到结果里

翻译缓存会把前后文一起计入缓存指纹，避免同一句原文在不同语境下复用不合适的旧译文。

## 批量任务与移动端

### 批量加入队列

1. 在文件浏览器点击「多选」。
2. 勾选一个或多个视频/字幕文件，或直接勾选目录复选框。
3. 按需设置批量轨道策略。
4. 点击「批量加入队列」。
5. 系统会为每个视频创建独立任务，可在「翻译历史」查看。

目录勾选会递归扫描子目录，默认只加入视频文件；外挂字幕不会单独入队。同一目录下相同 `SxxExx` 的多个版本可开启“同集多版本自动去重”，系统会保留体积最大的文件。

批量任务的轨道策略：

| 选项 | 说明 |
|------|------|
| 字幕语言优先 | 优先选择指定语言的非强制字幕轨；找不到时按默认轨/首轨回退 |
| 音轨语言优先（ASR） | 无可用字幕并回退 ASR 时，优先使用指定语言的音轨 |
| 优先默认轨 | 在同语言候选中优先使用默认轨 |
| 允许强制轨 | 默认关闭，避免把只含片头/标牌的强制字幕当成完整字幕 |
| 无字幕时 ASR | 没有文本/图像/外挂字幕时，是否自动改用语音识别 |

批量任务会使用当前翻译设置；如需为不同作品填写不同背景，建议分别创建任务。

### 键盘操作

- `Tab` / `Shift + Tab`：在可交互元素之间移动焦点。
- 文件目录树：
  - `Enter` / `Space`：选择文件或目录。
  - `→`：展开当前目录。
  - `←`：折叠当前目录。
- 页面顶部提供“跳到主要内容”链接，键盘用户可快速跳过导航。
- 已适配 `prefers-reduced-motion`，系统开启减少动态效果时会降低动画。

### 移动端

- 底部导航：首页 / 历史 / 媒体库 / 自动化 / 设置。
- 首页文件浏览器通过「文件 / 翻译设置」Tab 切换。
- 核对页建议使用桌面端完成大量编辑；移动端可用于快速查看和少量修改。

## 无字幕视频与语音识别

### 内置 ASR 与手动下载模型

单镜像已经内置 ASR 服务，不需要再启动 sidecar。

首次使用：

1. 进入「设置 → 语音识别」。
2. 在「本地模型管理」中确认当前引擎（自动 / faster-whisper / whisper.cpp）。
3. 点击模型右侧「下载」。
4. 页面显示进度、速度、剩余时间和当前文件；可暂停、继续、取消或卸载。
5. 下载完成后开启「启用语音识别」。

有字幕也能用 ASR。一句话：**字幕好用字幕，字幕烂或没有字幕就用 ASR；两个都想试，直接打开开关。**

- 选中视频后，右侧「语音识别」卡片始终可用（只要检测到音频轨道）。
- 视频没有文本字幕时，默认自动走 ASR。
- 视频已有文本字幕时，默认仍用字幕；想重新听写、修正错字或处理字幕质量差的片源，打开开关即可强制走 ASR。
- 开启后会忽略当前选中的文本/图像字幕轨道，改用所选音频轨道重新识别。
- 关闭开关不会取消已选视频，也不会丢失字幕/音频轨道选择；如果视频没有文本或图像字幕轨，开始按钮会禁用并提示原因。
- ASR 提取的音频缓存在 `temp/asr-audio`（容器内 `/app/temp/asr-audio`），默认保留 14 天；失败任务会保留缓存供重试复用，成功任务默认删除，可用 `ASR_AUDIO_CACHE_DAYS` 调整。

默认地址：

```text
http://127.0.0.1:8000
```

设置页可以点击「使用内置」快速恢复该地址。拆分部署时才需要改成 sidecar 服务名。

### ASR 长任务超时

「设置 → 语音识别 → 长任务超时」可以调整四项参数，修改后对新任务生效：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 音频上传超时 | 30 分钟 | 上传音频、创建 ASR 任务的最长等待时间；网络慢或文件很大时可调大 |
| 状态请求超时 | 30 秒 | 单次查询识别进度的等待时间；一般无需修改 |
| 无进度超时 | 30 分钟 | 连续没有进度或阶段变化才判定卡死；排队等待不会触发 |
| 总任务上限 | 6 小时 | 单个 ASR 任务的绝对最长执行时间，到时一定中止并取消远端任务 |

低配 NAS、超长视频或 `large-v3` 模型可以适当调大“无进度超时”和“总任务上限”。不建议无限放大，否则服务卡死后会长期占用 CPU、内存和推理锁。

模型下载说明：

- 模型保存在 `./data/models`，不打进镜像。
- 中断后重新开始会从 `.part` 断点续传。
- 下载代理：页面顶部填写，或设置 `ASR_DOWNLOAD_PROXY`；仅支持 HTTP(S)。
- Hugging Face 镜像站：设置 `ASR_HF_ENDPOINT`，例如 `https://hf-mirror.com`。
- 默认不会静默下载模型；未下载时任务会提示先去设置页下载。
- 低配建议 `small`，16GB 以上可试 `medium`，GPU 可选 `large-v3-turbo`。

### ASR 参数

- 模型：`tiny` / `base` / `small` / `medium` / `large-v3` / `large-v3-turbo`
- 设备：`auto` / `cpu` / `cuda`
- 精度：CPU 用 `int8`，GPU 用 `float16`；设备和精度会随识别请求传给 ASR 服务
- 语言：默认自动检测，也可固定源语言
- 引擎：`auto` / `faster-whisper` / `whisper-cpp` / `cloud`
- 预处理：关闭 / Demucs / DeepFilterNet（需要 enhanced sidecar）
- 说话人分离：pyannote PoC（需要 enhanced sidecar 和 HF_TOKEN）

ARM NAS 推荐 `whisper-cpp`；x86 推荐 `faster-whisper`。`auto` 会在 ARM 上优先选择 whisper.cpp。

### 云 ASR 兜底

默认关闭。开启后：

- 只有本地识别失败时才上传音频。
- 音频超过 24MB 时先压缩为 32kbps mono MP3；仍超限会报错。
- 地址使用 OpenAI 兼容 Base URL，例如 `https://api.openai.com/v1`。
- 适配层保留扩展位，Azure/Google/豆包暂未作为首阶段重点。

### 拆分部署与增强能力

如果确实需要拆分部署：

```bash
docker compose --profile asr up -d asr
```

设置页 ASR 地址改为 `http://subx-asr:8000`。

增强 sidecar：

```bash
docker compose --profile asr-enhanced up -d asr-enhanced
```

设置页 ASR 地址改为 `http://subx-asr-enhanced:8000`。

- Demucs：分离人声后再识别，适合背景音乐较重的视频。
- DeepFilterNet：降噪后再识别。
- 预处理失败会自动回退原始音频，不阻塞任务。
- 说话人分离需要 `HF_TOKEN` 和 pyannote 模型许可；失败会回退普通识别。
- 说话人标签会写入识别详情，并在任务详情中展示。
- 增强镜像体积较大，默认关闭；预处理和分离失败都会自动回退原始音频。

### 处理视频

批量任务和自动任务会优先使用文本字幕，没有文本字幕时才走 ASR；手动任务可以在有字幕时主动打开「语音识别」开关，强制重新听写。

1. 首页选择没有文本字幕的视频。
2. 页面会显示「语音识别」区域。
3. 选择音频轨道。
4. 开始翻译。
5. 系统依次执行：音频提取 → 语音识别 → 字幕生成 → 翻译 → 核对 → 导出。

### 注意事项

- 模型下载前请为 `./data/models` 预留 10–20GB。
- J1900/J4125 等老 CPU 建议 `small` 或云兜底。
- 无 GPU 时不要默认加载 `large` 模型。
- ASR 任务详情会显示源语言、模型、平均置信度、说话人和识别日志。
- 长视频分段识别时，「语音识别」页会随已完成分段持续追加识别内容，不必等整个任务成功；页面每 8 秒按需刷新，只在打开该 Tab 时轮询。
- 实时预览直接读取已完成分段的 ASR 检查点，不会额外调用模型，也不会增加当前分段推理负载。默认分段 300 秒，因此通常约 5 分钟追加一批；当前分段内部仍显示实时进度百分比。
- 「下载原始」会导出 ASR 原始字幕，而不是视频内嵌字幕。
- 设置页 ASR 指标面板可查看识别次数、音频时长、RTF、平均置信度和引擎分布。

### Emby 兼容输出

在设置页开启「Emby 兼容输出」后：

- 媒体目录写入 `影片名.srt` / `影片名.ass` 主字幕。
- 语言变体写入 `SubX/影片名.zh-CN.srt`。
- 外挂字幕任务不会覆盖原文件。

## 图像字幕 OCR

一句话：**片子里的字幕是“图片”而不是文字时，把 OCR 打开就行；不用额外下模型。**

单镜像已经内置 PGS / VobSub / DVD 图像字幕 OCR，不需要额外启动 sidecar，也不需要下载模型。

启用步骤：

1. 进入「设置 → 图像字幕 OCR」，开启「启用图像字幕 OCR」。OCR 与语音识别是并列入口，不再放在语音识别页里。
2. OCR 服务地址保持 `http://127.0.0.1:8001`，或点击「使用内置」。
3. 选择 OCR 语言，例如 `zh-CN`、`en`、`ja`。
4. 选择 OCR 引擎：`auto`、`rapidocr` 或 `tesseract`；低置信度提示阈值默认 25%。
5. 首页选择带图像字幕的视频，轨道会显示 `[OCR]`；也可以让 `auto` 自动判断。

处理顺序：

```text
文本字幕 → 图像字幕 OCR → 语音识别
```

实现说明：

- PGS 使用 FFmpeg 提取 `.sup`，文件名会携带轨道语言，强制轨额外带 `.forced` 标记；再由 pgsrip + Tesseract/RapidOCR 按字幕 cue 识别。长电影不强制整片抽帧，pgsrip 失败时回退到分段位图 OCR。
- pgsrip 结果为空、文本过少或时间覆盖明显不完整时，会自动回退到字幕图像 OCR。
- VobSub / DVD 使用 FFmpeg 将位图字幕 overlay 到黑底后抽帧，先按字幕区域裁剪、放大、二值化，再做图像哈希去重和并行 OCR。
- 空白帧按字幕区域有效亮像素判断，不再使用整帧平均亮度，避免普通白色字幕被误判为空白。
- 默认 2fps；可用 `OCR_FPS` 调整，低配 NAS 可降到 1。
- 长视频按“分段时长”拆分处理，每段完成立即清理帧文件；同段失败可按设置重试。
- 分段断点保存在 `temp/ocr/subx-ocr-job-*`，任务重试时复用已完成分段，超过“断点保留”时间后自动清理。
- OCR 使用异步任务和进度轮询；PGS 识别期间会定时发送心跳，避免被误判为无进度。
- 低置信度结果会保留并进入核对页高亮，不再静默丢弃；可在设置页调整提示阈值。
- FFmpeg/pgsrip 失败时会把 stderr 摘要写入任务日志，便于区分位图字幕、路径和磁盘问题。
- 内置 OCR 与主应用共享同一个 `/media`，拆分部署时必须挂载相同的媒体目录。
- OCR 结果会进入正常翻译、核对和导出流程。
- 拆分部署仍可使用 `docker compose --profile ocr up -d ocr`，地址改为 `http://subx-ocr:8000`。

长视频参数在「设置 → 图像字幕 OCR → 长视频与超时」中调整：

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 最大视频时长 | 4 小时 | 视频时长超过后任务开始前直接报错，不会静默截断 |
| 分段时长 | 30 分钟 | VobSub/DVD 位图字幕按此长度分段处理 |
| PGS 识别超时 | 2 小时 | pgsrip 单次识别的最长等待时间 |
| 单段抽帧超时 | 1 小时 | 每个分段的 FFmpeg 抽帧/提取超时 |
| 单段重试次数 | 1 | 某个分段失败后的重试次数 |
| 断点保留 | 24 小时 | 失败任务的分段结果保留时间 |
| 无进度超时 | 60 分钟 | 主应用连续无进度后取消 OCR 任务 |
| 总任务上限 | 6 小时 | 单个 OCR 任务的绝对上限 |

对应环境变量仍可用于新实例默认值；设置页保存后以应用内参数为准。

## 存储与缓存

「设置 → 存储与缓存」用于查看磁盘和 SubX 自己生成的缓存占用，不会扫描或删除媒体文件。

| 类型 | 内容 | 清理建议 |
| --- | --- | --- |
| ASR 音频缓存 | 语音识别提取的 WAV，失败重试会复用 | 默认保留 14 天，可用 `ASR_AUDIO_CACHE_DAYS` 调整 |
| OCR 临时图像 | `temp/ocr` 抽帧目录与 `subx-ocr-job-*` 断点；兼容清理旧 `/tmp` 残留 | 长时间任务后检查 |
| 实景预览缓存 | `temp/preview` 下实景字幕预览生成的 PNG 和临时 ASS | 可清理，24 小时后也会自动回收 |
| 任务临时文件 | 字幕临时文件、音频片段、分块 partial | 按天清理 |
| AI 请求日志 | 翻译请求/响应调试日志 | 排障后可清理 |
| 任务日志文件 | `db/logs/task_*.log` | 按天清理 |
| 翻译缓存 | 数据库中的可复用翻译结果 | 可全部清理，后续会重新生成 |
| 本地模型 | Whisper 等模型文件 | 不参与缓存清理；在「语音识别 → 本地模型管理」卸载 |

- “清理旧缓存”按各类型的默认保留天数清理。
- “自动备份”可设置间隔小时数和保留份数，支持立即备份；应用内自动备份仅支持 SQLite，PostgreSQL 请使用 pg_dump。
- “全部清理”会跳过最近 5 分钟仍在使用的文件，并额外保护正在使用的 ASR 音频、任务临时文件和活跃 OCR 临时目录。
- 清理不会删除媒体、导出的字幕或模型。
- AI 请求日志默认只记录任务、模型、耗时、token、prompt/response 长度和解析结果摘要，不保存完整 prompt 与响应正文；排障确需完整正文时，显式设置 `SUBX_AI_LOG_FULL_PAYLOAD=1`，用完请关闭。

## 自动化

自动化页面位于顶部或移动端底部导航的「自动化」。

### 全局设置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 自动任务并发上限 | 1 | 同时运行的自动任务数，建议低配 NAS 保持 1 |
| 低置信度通知阈值 | 60% | ASR 平均置信度低于该值的片段数量大于 0 时触发通知 |
| 启用通知 | 开启 | 关闭后不再创建新的通知投递 |

### 规则模板

新增监控目录时可以先点模板：

- 电影库：递归、跳过 Sample/Trailer、最小 100MB。
- 剧集库：适合 SxxExx，稳定 20 秒。
- 动画 / 番剧：跳过 NCOP/NCED/Preview。
- 低配 NAS：单层目录、限制体积、延长稳定等待。
- 双语字幕：默认输出双语字幕。

### 新增监控目录

1. 进入「自动化 → 监控目录」，点击「新增监控目录」。
2. 选择媒体库，填写相对路径；留空表示整个媒体库根目录。
3. 选择触发模式：
   - **仅新文件**：只监听之后新增/变化的文件。
   - **仅历史回填**：不启动实时监听，只允许手动回填。
   - **新文件 + 回填**：两者都允许。
4. 设置递归、扩展名、正则、体积、时长、稳定等待等规则。
5. 设置目标语言、输出模式、字幕格式、字幕样式、双语布局、翻译风格和通知渠道。
6. 保存后，满足规则且稳定的新文件会自动创建任务。

也可以直接在「媒体库」页面右侧编辑器打开「自动监控」，等于创建一个监控整个媒体库根目录的配置。

### 过滤规则

| 规则 | 说明 |
|------|------|
| 视频扩展名 | 逗号分隔，例如 `.mkv,.mp4` |
| 包含/排除正则 | 对相对路径匹配；排除优先 |
| 最小/最大体积 | 单位 MB，0 表示不限 |
| 最短时长 | 单位秒，0 表示不限；大于 0 时会先 ffprobe |
| 创建/修改时间 | 可选范围，留空不限 |
| 文件稳定等待 | 大小和 mtime 稳定后才入队，默认 15 秒 |
| 已有字幕时跳过 | 同名字幕文件存在时跳过视频 |
| 已有目标输出时跳过 | 目标语言输出已存在时跳过 |
| 递归子目录 | 关闭后只处理当前目录第一层 |

临时文件、隐藏目录、`SubX/`、`@eaDir/`、`#recycle/` 会自动忽略。

### 幂等与防循环

事件去重键为：

```text
相对路径 + 文件大小 + mtime
```

同一文件在排队/处理中不会重复触发；输出字幕不会被再次当作视频处理；已有输出默认跳过，避免无限循环。

### 历史回填

点击监控目录卡片上的「回填」：

- 可指定修改时间起止和最多入队数量。
- 只扫描该监控目录，不默认全库扫描。
- 按全局自动并发逐步创建任务。
- 回填结果会写入事件记录，可查看跳过原因。

### 事件记录

「自动化 → 事件记录」展示：

- 文件路径、所属监控目录、大小、时间。
- 状态：待处理 / 已排队 / 完成 / 失败 / 已跳过。
- 失败原因和关联任务链接。
- 失败事件可点击「重试」重新入队。

## 通知渠道

支持 Telegram、SMTP 邮件、Webhook、ntfy、Discord、Matrix 和企业微信。

### Telegram

| 字段 | 说明 |
|------|------|
| Bot Token | 通过 BotFather 创建，加密保存 |
| Chat ID | 私聊/群组 ID，例如 `-1001234567890` |
| 代理地址 | 可选，支持 HTTP 代理 |

### 邮件 SMTP

填写 SMTP Host、端口、用户名、密码/授权码、发件人和收件人。465 端口通常开启 SSL；587 端口通常使用 STARTTLS。

### Webhook

- URL 必须为 http/https。
- 支持 POST / PUT / PATCH。
- Headers 使用 JSON 对象。
- 可设置 HMAC 密钥，请求会附带 `X-SubX-Signature: sha256=...`。
- 支持可选代理。

### ntfy

填写 ntfy 服务地址、Topic、可选访问 Token 和优先级 1-5。

### Discord / Matrix / 企业微信

- **Discord**：填 Discord Webhook URL。
- **Matrix**：填 Homeserver、Room ID 和 Access Token。
- **企业微信**：填群机器人 Webhook URL。

### 事件筛选与测试

每个渠道可以单独选择通知事件：

- 任务完成
- 任务失败
- 任务取消
- 低置信度
- 监控异常
- 回填完成

保存后点击「测试」会立即发送一条测试通知。发送失败会进入重试队列，不阻塞主任务。最近投递记录可在同一页面查看。

任务通知会包含文件、状态、输出模式、字幕格式、双语排版、字幕来源、目标语言、模型、翻译风格、任务来源、耗时、输出路径和错误信息，便于在 Telegram 等渠道直接判断任务结果。

## API Token 与 OpenAPI

进入「自动化 → API Token」创建 Token：

- 名称仅用于识别。
- 权限按 scope 拆分：
  - `tasks:read` / `tasks:write`
  - `automation:read` / `automation:write`
  - `tokens:manage`
  - `system:admin`
  - `*` 全部权限
- ASR 模型下载、暂停、续传、取消、卸载需要 `system:admin`；模型列表和状态读取需要 `tasks:read`。
- 可设置有效期；留空表示永不过期。
- 明文只在创建时显示一次，请立即保存。
- 可随时撤销；撤销后调用立即返回 401。

调用时使用：

```http
Authorization: Bearer subx_xxx
```

或：

```http
X-API-Token: subx_xxx
```

OpenAPI：

```text
GET /api/openapi.json
```

「最近 API 调用」会记录 Token 名称、方法、路径、状态码和时间，便于排查。

## 外部集成

支持 Sonarr、Radarr、Jellyfin、Plex、Emby、Bazarr 的 Webhook。

### 配置

1. 进入「自动化 → 外部集成」。
2. 生成 Webhook Token 并保存。
3. 如需映射下载器路径，填写：
   - 回调路径前缀，例如 `/downloads`
   - SubX 容器路径，例如 `/media`
4. 复制对应来源的 Webhook URL，填到下载器/媒体服务器。

示例：

```text
Sonarr:   http://NAS_IP:3000/api/integrations/sonarr?token=subx_hook_xxx
Radarr:   http://NAS_IP:3000/api/integrations/radarr?token=subx_hook_xxx
Jellyfin: http://NAS_IP:3000/api/integrations/jellyfin?token=subx_hook_xxx
Plex:     http://NAS_IP:3000/api/integrations/plex?token=subx_hook_xxx
Emby:     http://NAS_IP:3000/api/integrations/emby?token=subx_hook_xxx
Bazarr:   http://NAS_IP:3000/api/integrations/bazarr?token=subx_hook_xxx
```

### 行为

- Sonarr/Radarr 下载事件会读取 `episodeFile.path` / `movieFile.path`。
- Jellyfin 读取 `Item.Path`。
- Plex 读取 `Metadata.Media[].Part[].file`，不同版本字段可能不同。
- Emby 读取 `Item.Path` / `Path`。
- Bazarr 读取 `episode.path` / `movie.path` / `path`。
- 路径必须能映射到已配置的媒体库。
- 测试事件只返回成功，不创建任务。
- 成功/失败都会记录在「最近集成事件」。

### 任务状态

| exporting | 正在合成导出文件 |
| done | 翻译完成 |
| error | 翻译失败 |
| cancelled | 用户手动取消 |
| review | 兼容旧任务的待核对状态 |

### 查看任务进度

在 `翻译历史` 中点击任务行的 👁 按钮，进入任务详情页。桌面端使用表格，移动端使用任务卡片。

任务详情页已改为 Tab 结构：

- **概览**：进度、失败摘要、任务计时、媒体库、模型、目标语言、输出模式、字幕来源、字幕格式、分块进度。

  - 预计时间基于最近进度变化和当前阶段进度估算，仅供排障和安排时间参考。
- **日志**：分步日志、每块校验日志、实时进度。
- **诊断**：连接状态、翻译模式、token 用量、原始请求/响应、风险标签。

移动端 History 卡片会直接展示状态、进度、错误摘要和常用操作。

## 核对页面

### 进入方式

翻译历史页只会在任务存在核对数据、或可以从已导出/源字幕回填时显示 📋 按钮。点击进入核对页。

核对页显示字幕内容的前提：

- 任务已经生成 `task_review_entries`，通常是「仅译文」或「双语」任务完成翻译后。
- 「仅原文字幕」任务会直接生成原始字幕核对记录。
- 旧任务没有核对记录时，会优先读取 `output_path` 指向的已导出字幕，再回退到外挂字幕源文件。
- 内嵌字幕 / OCR / ASR 任务只有在翻译流程生成了核对记录后才可核对；任务在翻译完成前失败或取消时没有内容。

如果页面提示「当前筛选下暂无字幕条目」，说明任务有数据但筛选条件没有匹配项，可点「重置筛选」。

### 页面布局

核对页桌面端分为左右两栏：

- **左栏**：字幕条目列表，支持筛选、选择、编辑。
- **右栏**：实时预览面板。

移动端：

- 条目列表单列展示。
- 顶部「预览」按钮打开全屏预览抽屉。
- 高频操作保留在顶部，平移/错位修正收进「更多」。

### 筛选功能

核对页使用紧凑工具条：搜索和常用快捷筛选常显，完整筛选项收进「筛选」弹出层；页面会显示当前启用的筛选数量。

顶部筛选区域：

| 筛选器 | 选项 | 说明 |
|--------|------|------|
| 搜索 | 原文 / 当前译文 / 最终导出 / 编号 | 输入关键词即时过滤 |
| 状态筛选 | 全部 / 待核对 / 已翻译 / 同文可接受 / 已回退 / 缺失 / 已编辑 / 待保存 / 仅已选 | 按条目状态过滤 |
| 内容筛选 | 需要处理 / 未翻译或同文 / 译文为空 / 译文与原文相同 / 导出与原文相同 / 导出已调整 / 译文偏原语言 / 译文异常偏长 | 按文本内容特征过滤 |
| 原因筛选 | 全部原因 / 缺少译文 / 译文与原文相同 / ... | 按系统记录的核对原因过滤，括号内为条数 |
| ASR 置信度 | 全部 / 低于 60% / 无置信度 | 按语音识别置信度过滤 |
| 翻译质量 | 全部 / 低于阈值 / 高于阈值 / 未校验 | 按双模型质量分过滤，阈值默认 70% |

「译文与原文相同」会忽略标点、空格、大小写和格式标签，因此 `<i>Hello</i>` 与 `Hello` 会被视为相同。该筛选适合找出 AI 没有真正翻译的条目。

快捷筛选：

- **需要处理**：合并空译文、同文、待核对、低质量、低置信度和有核对原因的条目。
- **未翻译 / 同文**：只筛空译文和译文与原文相同的条目。
- **低质量** / **低置信度** / **待保存**：快速切换到对应筛选条件。
- **重置筛选**：清空搜索和所有筛选条件。

页面顶部提供「操作指南」入口，完整说明筛选、选择、重译、保存和导出的结果。

### 快捷选择按钮

- **全选筛选结果**：选中当前筛选结果中的所有条目（跨页生效）
- **选待核对**：选中所有状态为 `needs_review`、`fallback_original`、`missing` 的条目
- **反选可见**：反转当前筛选结果的选中状态
- **清空选择**：取消所有选择

### 逐条操作

每个字幕条目包含三栏：

| 栏 | 内容 | 操作 |
|----|------|------|
| 原文 | 原始字幕文本 | 不可编辑 |
| 当前译文 | AI 翻译结果 | 可点击 ↑↓ 将译文与相邻条目互换；重译会覆盖此列 |
| 最终导出 | 即将写入文件的文本 | 可编辑 (Textarea)、恢复译文、使用原文、↑↓ 互换；只有此列会写入字幕文件 |

条目头部会根据内容显示「译文为空」「译文与原文相同」「导出已调整」「导出=原文」等标记，便于快速定位。

### 批量操作

| 按钮 | 功能 | 结果 |
|------|------|------|
| 重译选中 | 对已勾选条目重新发起 AI 翻译 | 覆盖当前译文和最终导出，清除旧质量分 |
| 重译筛选结果 | 对当前筛选出的全部条目重译 | 适合先筛出未翻译/同文再批量处理；会先弹出条数和费用提示 |
| 设为原文 | 将选中条目的最终导出设为原文 | 不改变当前译文；需要保存或导出后生效 |
| 所选上移/下移 | 整体移动选中的条目顺序 | 改变字幕顺序，需保存或导出 |
| 译文下移/上移 | 从第一个选中条目起，所有译文字段整体偏移一行 | 用于修正 AI 错位，位于「更多」菜单中 |
| 保存修改 | 将当前待保存编辑写入数据库 | 不会生成字幕文件；导出时会再次自动保存 |

重译、设为原文、放弃成果等批量或不可逆操作都会弹出确认框，说明影响范围和后续结果。

### 分页与快捷键

- 核对页默认每页 100 条，可切换 50 / 100 / 200 条。
- 筛选条件变化时自动回到第一页。
- 键盘快捷键：
  - `J` / `K`：下一条 / 上一条
  - `Enter`：编辑当前条目的最终文本
  - `Ctrl/Cmd + S`：保存修改
- 输入框、文本域和选择框内不会触发全局快捷键。

### 音频片段回放

每条字幕右侧有播放按钮：

- 点击后播放该条字幕对应的视频音频片段。
- 默认最多播放 30 秒，缓存在 `temp/clip_*`。
- 需要任务源视频仍可访问；媒体目录被移除后会播放失败。

### 实时预览与 AI 校对

桌面端右侧面板提供「实时预览 / AI 校对」分页，移动端 AI 校对使用抽屉；两者共享同一份缓存结果。

预览面板支持：

- **格式切换**：SRT / ASS。
- **双语排版**：译文在上 / 原文在上。
- **自动刷新**：切换导出模式、字幕样式时自动刷新。
- **手动刷新**：点击“刷新”按钮。
- **移动端**：点击顶部「预览」打开抽屉查看。

导出设置中的高级样式抽屉还提供「实景预览」：从任务关联视频抽取当前字幕时间点附近的画面，按完整分辨率烧录字幕样式。预览图可查看原图或下载，便于实际核对字号、颜色、描边和底部位置。

### 导出最终字幕

1. 在核对页完成所有编辑和确认
2. 点击页头「导出设置」打开设置弹层：
   - **导出模式**：仅译文 / 双语 / 仅原文
   - **字幕样式**：与首页共享同一套 ASS 预设
   - **导出格式**：SRT / ASS
   - **高级样式**：打开独立样式面板，按原文/译文分别调整字体、字号、颜色、描边和布局
3. 点击"导出结果"
4. 系统会自动保存修改（包括核对页调整后的顺序）→ 生成文件 → 标记任务为 done
5. 如果目标字幕文件已存在，会先把旧文件备份为隐藏的 `.原文件名.subx-backup-时间`，同一文件最多保留 5 份备份

导出文件以每条字幕的「最终导出」列为准；「当前译文」只用于恢复和重译参考。

批量重译现在会进入后台任务：创建后立即返回，离开核对页也会继续执行；返回核对页时会自动恢复进度并刷新结果。

### 放弃成果

点击"放弃成果"会弹出不可撤销确认。确认后任务状态会设置为 `error`，表示放弃本次翻译结果，未保存的编辑也会一并丢弃。

## 字幕导出与格式

### 输出文件命名

```
原视频文件名.{语言代码}.{格式}

例如：阿索卡 - S01E01 - 第 1 集.zh-CN.srt
```

### SRT 格式

- 纯文本字幕格式，兼容所有播放器
- 支持双语（原文+译文分行显示）
- 不包含任何样式信息

### ASS 格式

- 高级字幕格式，支持样式、定位、特效
- 如果原始字幕是 ASS，会优先保留原始时间轴和事件结构
- 选择预设或自定义样式时，会使用 SubX 生成的字体、颜色和定位；需要完全保留源 ASS 样式时请选择“沿用原样式”
- 8 种预设样式：
  - **简洁双语**：译文清晰 + 原文小字灰色
  - **影院双语**：译文更大更粗，原文更小
  - **学习双语**：原文更醒目，适合语言学习
  - **紧凑双语**：更小字号和行距
  - **单色双语**：原文和译文使用接近的单色
  - **单语清爽**：只显示一种语言，字号适中
  - **单语紧凑**：更小字号和边距
  - **沿用原样式**：优先保留原 ASS 样式
- 双语会生成原文/译文两个 ASS Style 和两组事件，因此可以分别设置字体、字号、颜色、描边、阴影、加粗、斜体和垂直边距。
- 支持可选背景框、透明度、颜色和内边距。

### `__SUBX_FMT_N__` 占位符

这是系统内部使用的格式化保护标记。在以下情况下你可能会看到：

- 核对页的"当前译文"或"最终导出"文本中
- AI 返回的原始响应中

**这些占位符不会出现在最终导出的字幕文件中**。系统在写入文件前会自动清除所有这类标记。

## 日志与排查

### 任务日志

每个任务的详细执行日志保存在两个位置：

| 位置 | 路径 | 保留策略 |
|------|------|---------|
| 数据库 | `task_logs` 表 | 随任务删除而删除 |
| 文件系统 | `db/logs/task_<任务ID>.log` | 受"日志保留天数"控制 |

查看文件日志：

```bash
docker exec subx cat /app/db/logs/task_<任务ID>.log
```

### 任务失败排查步骤

1. **进入任务详情页**：查看错误日志和诊断信息
2. **检查原始响应**：展开"诊断信息"区域，查看 AI 返回的原始内容
3. **检查容器日志**：
   ```bash
   docker compose logs -f subx
   ```
4. **常见失败原因**：

| 错误类型 | 可能原因 | 解决方案 |
|----------|---------|---------|
| 鉴权失败 (401) | API Key 无效或格式错误 | 检查 API Key 是否正确 |
| 速率限制 (429) | 调用过于频繁 | 降低并发数，等待重试 |
| 请求超时 | 网络不通或模型响应慢 | 检查网络，考虑更换模型 |
| 解析异常 | AI 返回格式不规范 | 检查 AI 返回内容，降低 chunkSize |
| 流式请求失败 | 连接中断 | 切换为非流式模式 |

### 校验日志

翻译过程中会输出如下日志：

```
[校验] 块 #1 AI 返回 140/140，有效 140/140，未改动原文: 10 条(将进入核对)
```

- **AI 返回**：AI 实际返回的条目数
- **有效**：被接受的条目数（非空译文）
- **未改动原文**：AI 未翻译的条目（音乐符号、专有名词、繁简同形等），将在核对页中以 `accepted_same` 状态列出

## 常见问题

### 安装与部署

**Q：容器启动后页面无法访问？**

检查端口映射、防火墙、容器是否正常运行：`docker compose ps && docker compose logs subx`

**Q：HTTPS 反向代理后登录异常？**

确保反向代理透传了 `X-Forwarded-Proto: https` 请求头。

**Q：容器内看不到媒体文件？**

- 检查 `docker compose` 中的 `volumes` 挂载是否正确
- 确认填写的是容器内路径（如 `/media/tv`），不是宿主机路径（如 `/volume1/tv`）
- 确认容器用户对目录有读取权限

### 翻译相关

**Q：翻译结果全部是原文，没有译文？**

AI 返回了翻译但被校验拒绝。查看任务日志中的"未改动原文"数。如大量条目为原文，检查：
- API Key 对应的模型是否有余额
- 模型是否支持目标语言翻译
- chunkSize 是否过大导致模型输出截断

**Q：翻译后字幕时间轴偏移？**

SubX 保留原始时间轴，不应出现偏移。如确实偏移，可能是原始字幕文件本身的时间轴问题。

**Q：能否只翻译部分字幕？**

目前不支持选择性翻译部分条目。但可以在翻译完成后进入核对页，对不满意的条目单独重新翻译。

**Q：支持哪些 AI 模型？**

所有兼容 OpenAI 接口的模型都可以使用，包括：
- OpenAI：GPT 系列
- DeepSeek：deepseek-chat / deepseek-v3 等
- Gemini（通过兼容接口）
- 第三方代理/中转服务

### 核对页

**Q：翻译完成但核对页没有内容？**

- 「仅译文」或「双语」任务完成后会生成核对记录。
- 「仅原文字幕」任务也会生成原始字幕核对记录。
- 旧任务没有核对记录时，会优先从已导出的 `output_path` 字幕回填，再回退到外挂字幕源文件。
- 任务在翻译完成前失败或取消、且没有可回填字幕时，页面会明确提示“没有可核对的字幕数据”。

**Q：如何修复 AI 翻译"串位"的问题？**

在核对页使用"译文上移"/"译文下移"按钮调整。如果全部偏移了一行，选中偏移起始条目，点"译文下移"。

**Q：核对页的修改会自动保存吗？**

不会自动保存。修改后需点击"保存修改"按钮。但在导出、批量重译前会自动保存。

**Q：为什么核对页能看到 `__SUBX_FMT_1__` 这样的标记？**

这些是系统内部的格式化保护标记（保护 `<i>` 等 HTML 标签在翻译过程中不被 AI 修改）。在最终导出时会自动清除，不会出现在字幕文件中。

### 其他

**Q：Windows Edge 最小化后会自动弹回？**

这是 Edge 与 Vue Router 在 `visibilitychange` 时写入滚动位置有关的兼容性问题。SubX 已加入仅对 Edge 生效的规避补丁；如仍出现，请升级到包含该修复的版本，并确认没有使用旧缓存页面。

**Q：长视频语音识别可以暂停/继续吗？**

可以。ASR 任务会按分段识别并保存检查点：

- 任务页支持「暂停任务」/「继续任务」。
- 暂停会在当前识别分段完成后生效。
- 继续任务会复用已完成的识别分段，只处理剩余分段。
- 失败重试和容器重启后也会复用已有分段。
- 检查点默认保留 168 小时。分段时长、分段重叠和检查点保留时间可在「设置 → 语音识别 → 分段与断点」调整，也可通过 `ASR_CHUNK_SECONDS` / `ASR_CHUNK_OVERLAP_SECONDS` / `ASR_RESUME_TTL_HOURS` 设置默认值。段越短，暂停生效越快，但调用次数更多。

**Q：如何备份数据？**

推荐使用内置脚本，备份数据库、`.secret` 和任务日志：

```bash
npm run backup
# 或指定输出目录
node scripts/backup-sqlite.mjs --out ./backups
```

恢复前请先停止 SubX，再执行：

```bash
npm run restore -- ./backups/subx-2026-01-01T00-00-00-000Z
```

恢复脚本会校验备份数据库完整性，并先把当前数据库另存为 `.pre-restore-*`。也可以手动备份 `db/` 挂载目录，包含数据库文件、任务日志和 AI 响应日志（日志保留天数内）。

**Q：升级后设置会丢失吗？**

不会。设置保存在数据库中，只要 `db/` 目录持续挂载就不会丢失。

**Q：支持繁体中文翻译吗？**

支持。设置"目标语言"为 `zh-TW` 即可。但 AI 模型必须支持繁体中文输出。

**Q：支持从视频中提取双语字幕吗？**

SubX 提取的是视频内嵌的单语言字幕。如需双语，选择"双语对照"输出模式，系统会保留原文并在上方/下方添加译文。

**Q：任务日志文件会持续增长吗？**

不会。日志文件、临时文件和翻译缓存受“日志保留天数”控制，默认 7 天自动清理；删除任务或清空历史时也会同步清理对应记录和文件。

**Q：如何提高翻译成功率？**

1. 增大分块大小（如 8000-10000），减少上下文断裂
2. 使用翻译能力更强的模型
3. 对于复杂字幕，翻译完成后进入核对页手动调整
4. 添加术语表改善专有名词翻译质量
