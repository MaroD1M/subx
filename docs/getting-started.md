# SubX 快速开始

> 适用版本：v2.10.1
>
> 前置条件：已完成 [部署](deployment.md)，容器健康且能打开 Web 界面。

本页覆盖首次访问、AI 接口、媒体库、第一个翻译任务和任务管理。更细的功能说明见下方相关文档。

## 首次配置

### 首次访问

1. 打开浏览器访问 `http://<主机IP>:3000`
2. 首次访问会跳转到 `/login`，设置一个访问口令（最少 8 位）
3. 设置成功后自动登录

### 配置 AI 接口

1. 点击桌面左侧导航或移动端底部导航的「设置」，进入 `/settings` 页面
2. 在 AI 连接区域填写：
   - **接口密钥**：你的 API Key
   - **接口基础地址**：如果使用第三方代理/中转，修改此地址
   - **默认模型**：点击刷新按钮获取可用模型列表，或手动输入模型名
3. 测试连接是否正常：模型列表成功加载即为正常

### 配置媒体库

1. 点击桌面左侧导航或移动端底部导航的「媒体库」
2. 左侧列表选择媒体库，右侧编辑名称、容器内路径和状态
3. 添加一个或多个容器内路径（注意是**容器内路径**，不是宿主机路径）
4. 例如 Docker 挂载了 `/volume1/video:/media/movies`，则应填写 `/media/movies`
5. 点击「检测」或「批量检测」确认挂载和权限正常
6. 保存配置。保存后会留在当前页面，可继续编辑。自动监控统一在「自动化 → 监控目录」中配置

媒体库页面会校验空名称、空路径、重复路径和默认库，并标记异常状态。媒体库较多时，左侧列表支持按名称/路径搜索，以及按全部、启用、停用、异常筛选；右侧只编辑当前选中的媒体库，类似 Sonarr / Radarr 的 master-detail 设置页。保存时只重新检测新增或路径变化的媒体库；需要刷新全部状态时使用「批量检测」。自动监控统一在「自动化 → 监控目录」中配置；停用媒体库不会自动停用已有监控配置，请到自动化页面自行停用；删除媒体库会清理对应监控配置。删除媒体库不会删除宿主机文件。

### 开始第一个翻译任务

1. 返回首页，在文件浏览器中选择一个视频文件（支持 `.mkv`、`.mp4`、`.avi`、`.webm`、`.ts`）
2. 左侧视频窗格会自动探测字幕轨道，选择需要的轨道
3. 右侧翻译选项区域设置参数
4. 点击"开始翻译"

## 设置页面

设置页使用独立页面和两级导航：先选择「连接 / 翻译 / 智能增强 / 系统」分组，再进入对应分区。存在未保存修改时，切换路由或关闭浏览器会提示确认，避免配置丢失。新增「系统体检」分页，可检查数据库、媒体库、FFmpeg、字体、临时目录、磁盘、AI 配置和备份状态：

- **AI 连接**：密钥、接口地址、默认模型。
- **语音识别**：内置 ASR/OCR 地址、识别参数、模型下载、暂停/续传/代理。
- **翻译默认**：目标语言、输出模式、翻译模式、分块大小、并发、重试、日志保留。
- **翻译风格**：自定义风格管理和内置风格参考。
- **术语表**：专有名词、角色名和固定译法。
- **智能增强**：简繁双输出、字幕质检、翻译记忆、成本预算和 TMDB 元数据。
- **高级设置**：流式用量统计等兼容性选项。
- **存储与缓存 / 系统体检**：磁盘占用、备份和运行状态检查。

> Docker 部署参数见 [部署文档](deployment.md)，环境变量完整参考见 [环境变量参考](reference/environment.md) 与根目录 [`docker-compose.yml`](../docker-compose.yml)。

### 简单模式

- 左侧栏底部或设置页顶部可切换「简洁模式 / 完整模式」。
- 简洁模式会隐藏「自动化」入口，并隐藏设置中的高级设置、存储与缓存、系统体检。
- 首页文件浏览器会隐藏翻译风格、作品背景/追加要求和高级字幕样式，只保留目标语言、输出模式、字幕格式、基础布局、轨道选择和开始翻译。
- 简洁模式保存在当前浏览器，不影响其他设备或已保存配置。

## 翻译任务管理

### 任务状态

| 状态 | 说明 |
|------|------|
| queued | 已创建，等待执行 |
| probing | 正在分析字幕/音频轨道 |
| extracting | 正在从视频提取字幕轨道 |
| extracting_audio | 正在提取 ASR 音频 |
| transcribing | 正在进行语音识别 |
| ocr | 正在进行图像字幕 OCR |
| parsing | 正在解析字幕文件并分块 |
| translating | 正在进行 AI 翻译 |
| exporting | 正在合成导出文件 |
| done | 翻译完成 |
| error | 翻译失败 |
| cancelled | 用户手动取消 |
| review | 兼容旧任务的待核对状态 |

### 查看任务进度

在 `翻译历史` 中点击任务行的 👁 按钮，进入任务详情页。桌面端使用表格，移动端使用任务卡片。

任务详情页已改为 Tab 结构：

- **概览**：进度、失败摘要、任务计时、媒体库、模型、目标语言、输出模式、字幕来源、字幕格式、分块进度。
  - 任务计时显示开始时间、已进行时间、当前阶段耗时、当前阶段预计剩余、整体预计剩余和预计完成时间。
  - 暂停时间会从有效耗时中扣除；完成、失败或取消后显示完成时间和总耗时。
  - 预计时间基于最近进度变化和当前阶段进度估算，仅供排障和安排时间参考。
- **日志**：分步日志、每块校验日志、实时进度。
- **诊断**：连接状态、翻译模式、token 用量、原始请求/响应、风险标签。

移动端 History 卡片会直接展示状态、进度、错误摘要和常用操作。

### 取消任务

在任务详情页点击"取消任务"按钮。取消后：

- 已发起的 API 调用会被立即中断（通过 AbortController）
- 已翻译完成的部分保留
- 任务状态变为 `cancelled`

### 重新翻译

在 `翻译历史` 中点击 🔄 按钮。系统会创建一个新任务：

- 跳过本地缓存，强制重新翻译
- 使用与原任务相同的设置

### 下载字幕

- 点击 ⬇ 按钮下载翻译结果
- 任务格式选择 `both` 时，会同时显示 SRT 和 ASS 下载按钮
- 任务详情页还有"下载原始"按钮，下载视频原始内嵌字幕

### 批量与分页

- 文件浏览器支持勾选多个文件后“批量加入队列”。
- 历史页支持按状态筛选、按文件路径搜索和分页；每页可切换 20 / 50 / 100 条，并提供页码导航。
- 存在运行中任务时，历史页会每 4 秒自动刷新；浏览器标签页隐藏时暂停，回到页面后立即恢复。
- 历史表格行支持悬浮高亮，移动端任务卡片有轻微上浮和阴影反馈，便于确认当前操作对象。
- 运行中的任务需要先取消，之后才能删除记录。

### 清空历史

点击"清空历史"按钮，可删除所有已完成/失败/已取消/待核对的任务，同时清理：

- `task_logs` 表
- `task_review_entries` 表
- `task_responses` 表
- `translations_cache` 表
- `db/logs/` 目录中的任务日志文件
- `temp/` 中对应的临时字幕和 partial 文件
